# Conta Bancária: Testes Automatizados

## Domínio
Sistema bancário simples, sem interface gráfica: criar conta, depositar, sacar, transferir e simular rendimento.

## Framework
C# (.NET) e xUnit.

## Como executar os testes
    dotnet restore
    dotnet test
